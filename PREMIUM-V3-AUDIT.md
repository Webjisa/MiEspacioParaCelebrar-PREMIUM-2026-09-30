# PREMIUM V3 · CONSOLIDACIÓN

Correcciones de consolidación realizadas después de la auditoría de PREMIUM V2.

- Logo oficial estabilizado con copia en raíz y fallback.
- Header y footer globales unificados.
- 404 real Premium.
- Fotografía principal de cada espacio priorizada mediante `space_images.is_main`.
- Eliminada la dependencia visual del footer antiguo.
- Portada sin lista fija de fotografías para el collage.
- Calendario Premium mantenido como componente visual común; el calendario legacy queda para el flujo de reserva existente hasta su sustitución funcional completa.
- No se ejecuta SQL ni se modifica Supabase.
